# Customer review collection

Collected 2026-09-23 from public source pages retrieved through web search. This is a dated snapshot, not a live feed. Search indexes and source caches can lag; the source link is authoritative for the current value.

## Selection rules

Customer ratings are separate from fit scores. No invented ratings or review counts. No expert/editorial scores, store-wide ratings, goalie sticks, mini sticks, custom builds, refurbished/pro stock equivalents, or scores belonging to a related-product carousel. A zero-review page has no rating, never 0/5. Do not claim every reviewer is a verified purchaser. Some reviews are promotional or syndicated.

Only the listed sizes are eligible for display. The primary source is a size-specific listing before combined/unclear scope, then source name alphabetically. It is not selected for having the highest score. Other collected sources for the same size are shown separately. Counts are never added or averaged across sources. Rating sorting acts on the recommended shortlist. The optional >4 filter applies before the 15-item cap and excludes missing ratings.

Bauer Nexus Tracer Junior and Senior show the same 50 reviews and 4.74 rating, so this is marked sizes combined. Other Bauer scope remains explicitly unconfirmed. Warehouse multi-size pages are marked combined/possibly combined, not junior-specific. Novium 2 Pro Youth page was retrieved from an older cached page; follow its link for current reviews.

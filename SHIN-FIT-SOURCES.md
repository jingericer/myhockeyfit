# Shin Guard Fit

This module is a starting-size guide and user-reported in-store fit checklist. It is not automated image analysis or a safety certification.

## Photos and privacy

Optional front and side photos can use a browser camera dialog with getUserMedia, preferring the rear camera, or a separate image file picker. The camera dialog provides framing prompts, a preview, retake and use controls. Camera permission and a secure context are required; failures direct the user to permission settings or the file picker. All stream tracks are stopped after capture, closing, leaving the tool and pagehide, including streams returned after a pending permission request was cancelled. Canvas data is cleared when closing. Blob URLs display local previews. No photo is transmitted, written to localStorage, or stored on a server. URLs are revoked on clear, leaving the store-check page, switching equipment, and pagehide. The app does not control an original photo already stored in the user's device gallery.

The result depends on four explicit answers: knee cup position, coverage, pad security, and movement. Any negative answer prompts adjustment; missing or uncertain answers require further checks. Four positive answers produce a qualified self-check result.
